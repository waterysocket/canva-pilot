# CanvaPilot

An open-source AI-powered Canva automation agent that understands natural language commands and autonomously edits presentations, documents, and designs within Canva. By combining computer vision, browser automation, and AI task planning, it acts as a local design copilot capable of executing complex Canva workflows while remaining transparent, customizable, and community-driven.

## Overview

CanvaPilot is designed to help creators, marketers, and teams automate repetitive design work in Canva through intelligent, natural-language instructions. Instead of manually clicking through menus and templates, users can describe what they want in plain English and let the agent handle the workflow.

## What it does

- Interprets natural language design requests
- Automates edits for presentations, documents, and visual assets
- Uses browser automation to interact with Canva workflows
- Applies computer vision and task planning to make decisions more reliably
- Provides a transparent, customizable, and open-source foundation for community contributions

## Why this matters

This project aims to make Canva workflows faster, more accessible, and more scalable by bringing AI-assisted design execution to local, community-driven development.

## Project goal

Build a practical local design copilot that can:

- understand creative requests,
- perform real Canva actions,
- and help users move from idea to finished design with less manual effort.
